# Archive — v0 planning documents

These documents describe the original karya design (v0.x): an AI-first terminal
IDE that orchestrates Neovim, tmux, and a coding-agent CLI. That product was
built and shipped (Phases 0–8, v0.6.0). They are kept for historical reference
and because much of the v0 foundation (isolation model, embedded assets, tmux
session orchestration, agent detection, self-update) carries forward into v1.0.

**The current, authoritative design is [DESIGN.md](../../DESIGN.md) at the repo
root.** Do not update files in this archive.

| File | What it was |
|---|---|
| `PLAN.md` | v0 architecture & design plan (isolation model, subsystems) |
| `ROADMAP.md` | v0 phased build order (Phases 0–8) |
| `PROGRESS.md` | v0 session-by-session progress log |
| `TOOLING_REFACTOR.md` | v0 tool-registry refactor design |
| `TOOLING_REFACTOR_PROGRESS.md` | v0 tool-registry refactor log |
